An invented passport spread for the Republic of Kestrelia — a small island nation in the southern Atlantic, a seabird sanctuary. A Node 22 program draws the open spread entirely in code: a data page with a portrait, fields and a machine-readable zone with correct ICAO check digits, and a visa page with arrival and departure stamps from the island's three neighbours, a visa condition (no night landings during kestrel roosting season) and a sanctuary-levy fee stamp.

## Run it

```sh
node main.ts
```

Writes one 1024x1024 PNG to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). Node 22+ standard library only, no network, deterministic — two runs produce byte-identical output.
